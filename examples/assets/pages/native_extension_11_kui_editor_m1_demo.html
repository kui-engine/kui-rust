Multi-cursor

  • Ctrl+D select next occurrence
  • Ctrl+Shift+L select all occurrences
  • Ctrl+Alt+Up/Down add cursor above/below
  • Alt+Click add cursor at click
  • Esc clear extra cursors

Find / Replace

  • Ctrl+F open find widget
  • Ctrl+H open replace widget
  • Enter next match · Shift+Enter prev
  • Tab switch find ↔ replace field

Line operations

  • Ctrl+/ toggle comment
  • Alt+Up/Down move line up/down
  • Shift+Alt+Up/Down copy line up/down
  • Ctrl+Shift+K delete line

Editing

  • Auto-pair ([{"'
  • Smart indent on Enter inside {}
  • Same-word + bracket match highlight while caret moves
