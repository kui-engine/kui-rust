CSS @supports

Feature Detection

@supports (display: flex) — Supported
@supports (display: grid) — Supported
@supports (aspect-ratio: 1/1) — Supported
@supports not (display: subgrid) — Not Supported
@supports applies styles conditionally based on CSS feature support

Syntax

@supports (display: flex) {
.container { display: flex; }
}
@supports not (display: subgrid) {
.fallback { display: grid; }
}
