KUI API — Platform services

Process-wide services through the C ABI (and the Go / Rust wrappers): the monotonic clock, timers, idle and cross-thread tasks, pumping the event loop by hand, the clipboard, monitors, system dialogs and the shell. On start the host runs every call once and checks the result; the clipboard is put back as it was. Grey buttons open modal dialogs or the browser, so the self-check never presses them.

Clock and timers

platform_now · set_timeout · set_interval · clear_timer · request_idle · post_to_main_thread

Timers, idle callbacks and posted tasks all run on the UI thread from inside the event loop; the clock is the one the timers use.

—

Pumping the event loop

platform_poll_events · wait_events

For hosts that own their loop: poll handles what is pending and returns, wait blocks until an event arrives or the timeout elapses. A posted task runs inside either.

—

Clipboard

platform_has_clipboard_text · get_clipboard_text · set_clipboard_text

The round trip saves the current text, writes a sample (with non-ASCII text), reads it back and restores the original. Clipboards that hold no text are left alone.

—

Monitors

platform_get_monitor_count · get_monitor · get_primary_monitor · get_monitor_from_point · get_monitor_from_window

Bounds and work area in virtual-screen pixels, the DPI scale, and which monitor holds a point or this window (looked up by its native handle).

—

Dialogs, shell, F12

platform_message_box · open_file_dialog · save_file_dialog · select_folder_dialog · open_url · set_f12_devtools_enabled

The dialogs are modal and the URL opens the system browser, so they are manual. With F12 enabled, pressing F12 starts DevTools and opens it in the browser.
