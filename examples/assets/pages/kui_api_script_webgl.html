Values across the boundary

set_global · get_global · function_create · function_call · function_retain · function_release

nil / bool / int / float / string / function values both ways, host functions as Lua values and Lua closures held by the host.

Errors & limits

get_last_error · set_instruction_limit · set_memory_limit · get_resource_usage

A runaway loop under a small instruction limit, an allocation over a small memory limit, a call to a missing function; limits are restored right after.

Print, files & document binding

set_print_handler · eval_file · unbind_document · bind_document

Lua print() goes to the host handler; a Lua file written by the host is run with eval_file; the engine is unbound from the document and bound again.
