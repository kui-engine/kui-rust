What is KUI?▶
KUI is a native C++ UI framework using HTML and CSS for building desktop applications with native performance.
How does rendering work?▶
KUI uses Google Skia for high-quality 2D rendering with GPU acceleration. The layout engine implements CSS box model, flexbox, and grid.
What scripting is supported?▶
KUI embeds Lua 5.4. You can manipulate the DOM, handle events, and create animations from Lua scripts.
What platforms are supported?▶
Currently Windows is fully supported. macOS and Linux support are planned. Architecture is designed for portability.
