KUI API — Window

The host drives the native window through the C ABI (and the Go / Rust wrappers): title, size and position, window events, maximize / fullscreen, frame shape, opacity, cursor, native menu bar, keyboard shortcuts, tray icon, DevTools and screenshots. On start the host runs every call once, checks the result and puts the window back exactly as it was. Grey buttons are for a person to try: they minimize the window, stop DevTools or open a system menu, so the self-check never presses them.

Title, size and position

window_get_title · set_title · get_size · resize · get_position · set_position · on_resize · add_event_listener / remove_event_listener / remove_event_listeners ("resize") · get_device_pixel_ratio · get_native_handle

Resizing reports the new client size through the on_resize callback and the window's "resize" event listeners.

Window state

window_maximize · restore · is_maximized · minimize · is_minimized · set_fullscreen · is_fullscreen · has_focus · should_close

Maximize and fullscreen are undone right away. Minimizing pauses rendering, so it is a manual button (restore the window from the taskbar).

—

Frame shape

window_set_frame_radius · set_frame_radii · get_frame_radii · clear_frame_radius · set_frameless · set_frameless_shadow · get_frame_state

Rounded corners (all four, or one radius per corner) and the frameless mode; the client area keeps its size when the frame is switched.

—

Opacity, z-order, cursor, IME

window_set_opacity · set_always_on_top · set_cursor · set_cursor_visible · set_ime_candidate_pos

The IME candidate window follows a custom caret: the button puts it under the input below.

—

Native menu bar

window_set_menu_bar · menu_set_checked · menu_set_enabled · clear_menu_bar

A "View" menu with a checkable item and an item that can be disabled; picking an item reports its id below.

—

Keyboard shortcuts

window_bind_shortcut · unbind_shortcut · unbind_all_shortcuts · set_shortcuts_enabled

F7 is bound at the window level (it fires before the page sees the key). The press button sends a real key message to the native window (Windows).

—

Tray icon

window_tray_is_active · tray_is_visible · tray_set_icon · tray_simulate_event · tray_popup_context_menu

The self-check creates a hidden tray icon (it may flash in the notification area for a moment), simulates clicks, which reach the tray callback like real ones, and removes it again. Popping up the context menu opens a system menu (manual).

—

DevTools and screenshot

window_get_devtools_port · get_devtools_state · stop_devtools · save_screenshot

The screenshot is written to the temp directory as PNG and removed again. Stopping DevTools disconnects any inspector (manual).
