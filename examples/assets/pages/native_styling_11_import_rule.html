CSS @import Rule

Syntax

/* Import external stylesheets */
@import url("reset.css");
@import url("theme.css");
@import url("components.css");

/* Conditional import */
@import url("mobile.css") (max-width: 768px);
@import loads external CSS. Must appear before other rules.

Use Case: Base + Theme

base.css
theme.css
Split styles into logical files for maintainability.
