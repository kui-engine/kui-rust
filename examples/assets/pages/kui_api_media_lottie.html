KUI API — audio, media elements & Lottie

The document's game-audio manager, <audio> / <video> elements and <lottie-player> driven from the host. Every call is checked against the state read back (handles, groups, counts, time, flags, playback state); without an audio device the checks are the same, only nothing is heard.
