KUI-039 · SDK 3.16.0 · DevTools 统一发现

我是 App %d / %d

本窗口 DevTools 监听端口 %u

一个地址发现全部

在浏览器或 MCP 连接 localhost:%u/json,即可聚合发现 本机全部 %d 个活跃 KUI target —— 连任意一个端口(%u..%u)都一样。

试一试

  • 1浏览器打开 http://localhost:%u/json
  • 2看到 %d 个 target 的聚合 JSON,各 webSocketDebuggerUrl 指向真实端口
  • 3Chrome chrome://inspect 配 localhost:%u 即可发现全部
  • 4本窗口精确 id 是 kui-%u；使用 kui_connect(target="kui-%u")
