KUI API — extensions & host-driven 3D

The host loads, inspects, unloads and reloads the kui_ext_3d extension through the C ABI (and the Go / Rust wrappers) and drives its <kui-3d-view> with extension calls: meshes, lights, materials, a glTF model and an orbit camera. Drag in the view to orbit (left button), drag with the right button to zoom, the wheel zooms in. On start the host runs every call once and checks the result.

Extension manager

extension_is_loaded · get_extension_state · extension_get_perf_stats · extension_reset_perf_stats · load / unload / reload_extension · unload_all_extensions · watch_extensions

Unloading removes the 3D element first; reloading loads the DLL again and rebuilds the scene in a fresh <kui-3d-view> that renders like the first one (also on the GPU zero-copy path). The self-check runs the cycle before the view exists.

Invoke results

extension_result_get_status · get_count · get_value · get_error · release

Status 0 is success, 3 an unknown method, 4 a wrong argument count; the error text explains a failure.
