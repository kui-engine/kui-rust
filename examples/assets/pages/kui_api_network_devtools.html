KUI API — HTTP client & DevTools commands

The host fetches over HTTP through the C ABI (and the Go / Rust wrappers) without the internet: the window's own DevTools server is a loopback HTTP server (/json/version), and a port with no listener produces a transport error. The DevTools functions run CDP commands in-process and inject mouse, key and IME input into the page. On start the host runs every call once and checks the result.
