KUI API — events

Listening to and dispatching DOM events from the host through the C ABI (and the Go / Rust wrappers): propagation, cancelation, listener management, and reading mouse, keyboard, focus and drag-and-drop details off the event object. On start the host dispatches synthetic events and injects real input to check every accessor; the panels then react to your own mouse and keyboard.
