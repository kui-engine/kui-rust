KUI API — geometry, scroll & focus

Layout geometry read back through the C ABI (and the Go / Rust wrappers): box metrics, scrolling, anchored placement, text measurement, focus and pointer capture. On start the host runs every call once and checks it against the CSS on this page; the buttons repeat the calls by hand.
