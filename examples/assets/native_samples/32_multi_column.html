Multi-Column Layout

column-count: 2

column-count: 2; column-gap: 24px;
CSS multi-column layout allows content to flow into multiple columns, similar to newspaper layouts. This is useful for presenting large blocks of text in a more readable format. The browser automatically balances the content across the specified number of columns. You can control the gap between columns and add decorative rules between them.

column-count: 3

column-count: 3; column-gap: 20px;
Three-column layouts work well for wider containers. The content is automatically distributed across all three columns. Each column gets roughly the same amount of content to maintain visual balance. This technique has been used in print design for centuries and is now available in CSS. Multi-column is great for articles, documentation, and any text-heavy content. It helps reduce line length, which improves readability. Users can scan content more naturally with shorter lines.

column-width: 200px

column-width: 200px; column-gap: 20px;
When using column-width instead of column-count, the browser determines the number of columns based on the available width. If the container is 600px wide with 200px column-width and 20px gaps, you might get 2-3 columns. This approach is more responsive — the column count adapts to the container size automatically.

columns shorthand

columns: 2 250px;
The columns shorthand property sets both column-count and column-width at once. This combines the best of both approaches — you get a target column count and a minimum column width. The browser will create up to the specified number of columns, but each will be at least the specified width.

column-rule (decorative divider)

column-rule: 1px solid #475569;
Column rules add a visual separator between columns, similar to a border. You can control the width, style, and color of the rule independently. Supported styles include solid, dashed, dotted, and double. The rule appears centered in the column gap and does not affect the column width or content flow.

Different Rule Styles

solid
Solid rule style is the most common. It creates a simple continuous line between columns.
dashed
Dashed rule style creates a series of short dashes as the separator between columns.
dotted
Dotted rule style uses small dots as the column separator for a lighter visual effect.
