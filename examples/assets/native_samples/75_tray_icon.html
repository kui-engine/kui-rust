ENH-P1-003 · 系统托盘图标 (TrayIcon)

KUI Native Desktop API · Win32 Shell_NotifyIcon 桥接 · 与 NativeMenuBar 对称设计

§1 API 概览

每个 Window 内置一个 TrayIcon 实例,通过 window:trayIcon() 暴露(C++)或 window.tray 暴露(Lua)。

方法说明
create(cfg)注册到 Shell,显示图标
destroy()从 Shell 删除
setTooltip(s) / tooltip()Hover 提示
setIcon(path)更新图标(.ico)
setVisible(b) / isVisible()显示/隐藏
onClick(fn)左键单击
onDoubleClick(fn)左键双击
onRightClick(fn)右键(自动弹出 contextMenu)
onBalloonClick(fn)气球通知被点击
setContextMenu(items)右键菜单(数组)
showBalloon(t, m, iconType, ms)系统气球/Toast 通知

§2 Lua 完整使用示例

-- 创建托盘图标
window.tray:create{
    icon    = "assets/app.ico",
    tooltip = "KUI App — running"
}

-- 单击切换窗口可见性
window.tray:onClick(function()
    if window.isVisible then window:hide() else window:show() end
end)

-- 右键弹出菜单
window.tray:setContextMenu({
    { text = "Show / Hide", onClick = function()
        if window.isVisible then window:hide() else window:show() end
    end },
    { isSeparator = true },
    { text = "Settings ...", onClick = function() openSettings() end },
    { isSeparator = true },
    { text = "Quit", onClick = function() window:close() end }
})

-- 后台任务完成后弹气球
function onSyncDone()
    window.tray:showBalloon("KUI", "Background sync complete", 1)
end

§3 C++ 完整使用示例

#include <kui/platform/window.h>
#include <kui/platform/tray_icon.h>

auto window = Window::create({ .title = "KUI App", .width = 800, .height = 600 });
TrayIcon& tray = window->trayIcon();

tray.create(window.get(), { .iconPath = "app.ico", .tooltip = "KUI App" });
tray.onClick([&] {
    if (window->isVisible()) window->hide(); else window->show();
});

MenuBarDef ctx;
ctx.addMenu("", {
    MenuItemDef("Show / Hide", [&] { /* ... */ }),
    MenuItemDef::separator(),
    MenuItemDef("Quit",        [&] { window->close(); })
});
tray.setContextMenu(ctx);

tray.showBalloon("KUI", "Saved", 1 /* info */);

范围所有者说明
