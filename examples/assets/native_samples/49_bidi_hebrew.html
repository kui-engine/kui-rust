R-23F — unicode-bidi 6 值在 Hebrew / Arabic / Latin 三语混排下的对照

§1 · isolate vs embed —— 外部上下文是否被打断

unicode-bidi: embed (RTL) — 内嵌但不隔离
Latin start עברית מוטבעת Latin end (12345)
外部数字「12345」可能被内嵌 RTL run 的方向影响
unicode-bidi: isolate — 完全隔离
Latin start עברית מבודדת Latin end (12345)
外部数字「12345」始终以外部基线方向呈现

§2 · isolate-override vs bidi-override —— 反向 + 隔离

unicode-bidi: bidi-override — 反向但不隔离
Pre ABCDEFG Post
外部 run 与反向 run 之间未隔离，可能产生方向溢出
unicode-bidi: isolate-override — 反向 + 隔离
Pre ABCDEFG Post
即使强制反向，也保持外部上下文不被打断

§3 · unicode-bidi: plaintext —— 内容首字符决定方向

plaintext + 首字符 Latin → LTR 段落
Hello עברית world
plaintext + 首字符 Hebrew → RTL 段落
עברית Hello mixed 12345
plaintext + 首字符 Arabic → RTL 段落
العربية mixed Latin 12345
plaintext 等价于 dir="auto" + isolate，常用于用户生成内容（UGC）的安全显示

§4 · 三语混排（Hebrew + Arabic + Latin）

三语 run + isolate 嵌套 —— 每段 RTL run 独立隔离不互染
Title: [עברית] + [العربية] = [Mixed text]
同一段落内 RTL 长 run 与 LTR 短 run 交替（基线 RTL）
המשפט הזה נכתב בעברית ומכיל גם English fragment וגם מספרים 2026 ואחר חוזר לעברית.
基线 LTR 但内含长 Hebrew run + Arabic run
English baseline mixing קטע בעברית with Arabic قطعة عربية and ending in Latin.

§5 · 嵌套隔离深度 ≥ 3 —— 多层 isolate 运行序列

3 层嵌套：LTR 外 → RTL Hebrew → LTR 内嵌 → RTL Arabic
Outer: עברית outer Inner LTR عربية innermost end inner עברית tail outer end.
4 层嵌套（正确边界 + isolate 保护，不会方向泄漏）
L1 עברית L2 Latin L3 עברית L4 L3 end L2 end L1 end

§6 · 数字 + Unicode 方向控制符

在 RTL 段中，欧洲数字（European numerals）默认方向 LTR
הזמנה מספר 2026-04-12, סה"כ 1,234.56 ש"ח (משולם)
在 RTL 段中，逆向数字 Hebrew —— 仍 LTR 顺序呈现
תאריך: 12/05/2026 שעה 09:30
U+202E RIGHT-TO-LEFT OVERRIDE 内联（不推荐使用，建议用 bidi-override）
normal then ‮reversed text‬ back normal

§7 · 实战场景：用户生成内容（UGC）安全混排

用 <bdi>（自动 isolate + dir=auto）保护未知方向的用户名 / 评论
User דניאל posted "Hello עולם world" at 09:30
User أحمد liked the post (42 likes total)
User 1234numeric_first joined the channel
UGC 列表（每个 <bdi> 独立判断方向，列表整体不被打断）
