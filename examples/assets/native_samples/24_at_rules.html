@font-face

@font-face { font-family: "MyCustomFont"; src: url("path/to/font.ttf"); }
@font-face rules are parsed; fonts are loaded from local file paths via SkiaBackend::addFontFromFile() before style resolution.
When a valid local font file path is specified in src: url(), the engine will load it into the Skia font manager and make it available for use with font-family references throughout the document.

@import（本地样式表）

@import "reset.css"; @import url("normalize.css");
@import 会按源顺序加载本地样式表，支持相对路径、嵌套、supports/media 条件与循环防护；远程 URL 不加载，layer()/layer 语义尚未实现。
