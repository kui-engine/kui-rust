KUI Frameless Window Demo

Frameless Window

This window has no native title bar or borders. The custom title bar above can be used to drag the window. The close/minimize/maximize buttons are not draggable (no-drag override).

Features

HTML <html frameless shadow sizeable>

Boolean attributes on the <html> element control window chrome. frameless removes the native frame, shadow enables DWM drop shadow, sizeable allows edge-drag resize.

CSS -webkit-app-region: drag

Makes an element act as a window drag handle. Inherited by children. Also available as -kui-app-region.

CSS -webkit-app-region: no-drag

Overrides inherited drag on child elements. Used for interactive controls (buttons, inputs) inside a drag region.

API Window::setFrameless(bool)

C++ API for programmatic frameless mode control. Also: setFramelessShadow(bool), setFramelessSizeable(bool).
