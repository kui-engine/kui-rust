1. PDF Pipeline Overview

KUI 的 PDF 导出走 layout → PageGeometry → Fragmenter → SkPDF 多页绘制 → close 五阶段， 全程零外部依赖（SkPDF 已含在 Skia 静态库中）。50 页 A4 letter 实测 60–256 ms， NFR-PDF-001 ≤ 2s 余量 > 7×。

1.1 调用入口

C++ 示例：

kui::PDFOptions opts;
opts.paperWidth_pt  = 612.0;   // letter
opts.paperHeight_pt = 792.0;
opts.title  = "";              // empty → auto-bridge from <title>
opts.author = "";              // empty → auto-bridge from <meta name="author">
doc->printToPDF("whitepaper.pdf", opts);

1.2 Lua 等价调用

document:printToPDF("whitepaper.pdf", {
    paperWidth_pt = 612, paperHeight_pt = 792,
})

2. @page Rule & Margin Boxes

2.1 Margin-box 16 个槽位

CSS Paged Media Level 3 §3.6 定义了 16 个 margin-box，KUI 全部识别：

  • 4 个角槽：@top-left-corner / @top-right-corner / @bottom-left-corner / @bottom-right-corner
  • 顶部 3 槽：@top-left / @top-center / @top-right
  • 底部 3 槽：@bottom-left / @bottom-center / @bottom-right
  • 侧边 6 槽：@left-top / @left-middle / @left-bottom / @right-top / @right-middle / @right-bottom

本页可看到底部 "Page N of M" 来自 @bottom-center { content: "Page " counter(page) " of " counter(pages); }。

2.2 Pseudo-page

本文档使用 @page :first 为封面单独定义版式（无页眉/页脚）， 使用 @page :left / @page :right 为偶/奇页区分页码位置。

2.3 命名页 cascade

本节属于 @page chapter，由元素属性 page: chapter 触发； 上一节属于 @page toc；附录属于 @page appendix（landscape）。 KUI 通过 findDominantPageName O(n) DFS 解析每个 fragment 所属的命名页。

3. Fragmentation & break-* Control

3.1 break-before / break-after / break-inside

KUI 实现完整 7 个 CSSPropertyID（含 page-break-* legacy 别名）：

  • break-before: page | column | region | always | auto | avoid
  • break-after: page | column | region | always | auto | avoid
  • break-inside: auto | avoid | avoid-page | avoid-column | avoid-region

3.2 keep-together 语义（break-inside: avoid）

本段落与上方标题使用 break-inside: avoid，保证不会在中间被分到下一页； 如果当前页空间不够，整个块会整体推到下一页开始。Fragmenter 在主循环中检查 inside-avoid 约束，并在必要时回退到上一个 valid break point。

对于 IFC（行级），KUI 实现行级切分；对于 BFC（块级），按 block 子节点切分； 当前 R-24D 计划中将扩展到 Flex / Grid / Table。

3.3 偶/奇页强制（CSS3 break-before: left / right）

KUI 支持 break-before: left / break-before: right 强制下个 fragment 落在偶/奇页（必要时插入空白页对齐）。

4.2 体积优化

JPEG 嵌入直走 /Filter /DCTDecode，跳过 raster surface 重编码 —— 实测体积比传统 PNG 流减少 50–80%。 Tagged Tree 仅 +4–8% 文件增量，但提供完整 PDF/UA-1 无障碍语义。

4.3 性能对比（参考）

典型 50 页 A4 文档，KUI vs Chromium headless print-to-pdf：

  • 启动开销：KUI ≈ 50 ms，Chromium headless ≈ 800–1200 ms
  • 渲染时间：KUI ≈ 60 ms，Chromium ≈ 80–120 ms（接近）
  • 结果文件：KUI 平均小 12–15%（Tagged Tree 紧凑 + JPEG 直通）
