NEW @font-face

@font-face rule parsing is now supported. Custom fonts can be declared with font-family and src descriptors. The engine parses url() sources and makes them available via the font loading API.
@font-face { font-family: "Custom"; src: url("font.woff2"); }

NEW Multi-column layout

Multi-column layout allows content to flow across multiple columns automatically. This is useful for text-heavy content, creating newspaper-style layouts. Column count, width, gap, and decorative rules are all configurable. The browser balances content across columns for even distribution.

NEW writing-mode

vertical-rl
The writing-mode property controls text direction. vertical-rl flows top-to-bottom with columns right-to-left (traditional CJK). vertical-lr is similar but columns go left-to-right.
