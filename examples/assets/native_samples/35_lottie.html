Lottie Animation Player

Basic Usage

<lottie-player src="animation.json" autoplay loop></lottie-player>
autoplay + loop
static (no autoplay)
The <lottie-player> element renders Lottie JSON animations using Skia's built-in Skottie module. It supports autoplay, loop, and speed attributes.

Playback Speed

<lottie-player src="anim.json" autoplay loop speed="2">
speed=0.5 (slow)
speed=1 (normal)
speed=2 (fast)

Attributes Reference

src — Path to Lottie JSON file
autoplay — Start playing immediately
loop — Loop the animation
speed — Playback speed multiplier (default: 1)

Integration Notes

Lottie rendering uses Skia's built-in Skottie module — no separate third-party Lottie library is required, only a Skia build with Skottie enabled (see vcpkg-overlay-ports/skia). Without it, the element will render as a placeholder. The animation is driven by the existing CSS animation timer (~60fps).
