自定义右键菜单

<kui-context-menu> 就是页面里的一段 HTML：内容随便写，外观全由 CSS 决定；引擎负责右键时打开并定位 （贴边自动翻转）、点外面 / Esc / 窗口失活时关闭、点菜单项后关闭、上下键与回车。引擎自带的「剪切 / 复制 / 粘贴」菜单默认不弹。

1. 最简用法：默认外观

写 for="目标 id"（或者直接放在目标元素里面），菜单项用 text / shortcut / separator / disabled；菜单项里再放一个菜单就是子菜单。

2. 完全自定义外观：只是 CSS

配色、圆角、阴影、字体、悬停渐变、图标、分组标题、勾选项、危险项、子菜单——全部是作者样式表，引擎只加 open / highlighted 属性和位置。左边是同一个菜单的静态预览。

5. 引擎自带的默认菜单

输入框的「剪切 / 复制 / 粘贴 / 全选」菜单默认不弹（下面这个输入框右键没有菜单）。需要时任选一种开启：

<html context-menu>                          // 页面
document->eventDispatcher()
    ->setDefaultContextMenuEnabled(true);     // C++
kui_document_set_default_context_menu_enabled(doc, 1);  // C
右键上面的区域试试；菜单项的 click、menu-open / menu-close 事件会记在这里。
